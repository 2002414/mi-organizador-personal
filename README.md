# Proyecto: Mi Organizador Personal

**Tecnología utilizada:** Flutter y lenguaje Dart  
**Plataforma:** Android  


## 1. Introducción

El proyecto consiste en desarrollar una aplicación móvil llamada **Mi Organizador Personal**, cuyo propósito es permitir al usuario organizar sus actividades diarias de una manera sencilla y práctica. La aplicación fue desarrollada utilizando Flutter y Dart, y ejecutada en un dispositivo Android mediante un emulador.

## 2. Funcionalidades implementadas

La aplicación cuenta con las siguientes características:

- **Agregar actividades:** permite escribir y añadir nuevas actividades a la lista.
- **Completar actividades:** permite marcar las actividades terminadas.
- **Eliminar actividades:** permite retirar actividades de la lista.
- **Interfaz personalizada:** utiliza colores, iconos y textos personalizados.
- **Mensajes de confirmación:** muestra una notificación cuando se agrega una actividad.

## 3. Personalización de la aplicación

Se realizaron modificaciones respecto a la estructura inicial para darle una identidad propia:

- Nombre: Mi Organizador Personal.
- Color principal azul.
- Encabezado personalizado.
- Iconos para identificar las actividades.
- Botón para agregar nuevas actividades.
- Casillas para marcar actividades completadas.
- Botón para eliminar actividades.
